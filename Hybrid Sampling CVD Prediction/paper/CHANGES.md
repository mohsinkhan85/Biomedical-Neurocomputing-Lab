## Main change: evaluation protocol

The original pipeline applied hybrid sampling (SMOTEENN + ROS) to the whole
dataset *before* drawing the test set. Our reimplementation reproduces the
original numbers (HS_DT 99.78%, HS_XGBoost 98.23%, HS_MLP 98.45%), but shows
they are caused by data leakage:

- 100% of positive test records have an identical copy in the training set
  (4.6% when the test set is held out first);
- ENN deletes 19.9% of the real non-CVD records (the borderline cases)
  before the test set is drawn.

On 6,000 real records held out before sampling, the same models reach only
57.4–70.8% accuracy (AUC 0.57–0.81). The paper now reports both protocols
and proposes an improved, leakage-free pipeline (≈76% accuracy, ≈80% recall,
AUC 0.84, confirmed by 5-fold cross-validation).

## Corrections of errors in the original

- Text claimed 100% accuracy for HS_DT; the table showed 99.70%.
- Text gave SVM AUC 99.01% and MLP AUC 99.90%; the tables showed 93.06% and 99.40%.
- Text gave MLP accuracy 97.42%; the table showed 97.34%.
- Fig. 6 caption said "SMOTE" for SMOTEENN.
- References [19] and [39] were the same paper (merged).
- Two affiliations were both numbered 2. **We assumed Muhammad Bilal Qureshi
  holds both the COMSATS (ECE) and the Central Asian University affiliations;
  please verify.**
- Dataset size: the original text cites 253,680 records but 221,542 after
  deduplication, which corresponds to a truncated copy of the CSV (244,680
  rows). The revised paper uses the full Kaggle file (229,781 unique rows).
